# Release Notes — v1.0.0

初回リリースです。

## 機能

- **セッション使用率表示** — 5時間ウィンドウの使用済みパーセントをプログレスバーで表示
- **週間制限表示** — 7日間・全モデル合計の使用済みパーセントをプログレスバーで表示
- **リセット時刻** — 各制限のリセットまでの残り時間を自動計算（「○時間○分後にリセット」形式）
- **警告色** — 70% 超でオレンジ、90% 超でレッドに変化
- **ミニマイズ** — ボタン1つでカードを折りたたみ（状態はローカルに保存）
- **サイドバー配置** — チャット入力を邪魔しないサイドバー下部に配置

## 技術仕様

- Manifest V3 / Chrome Extension
- `fetch` / `XHR` インターセプトで API レスポンスからリアルタイムに使用状況を取得
- Shadow DOM によりページの CSS と完全分離
- 設定パネルを開かなくても自動取得
