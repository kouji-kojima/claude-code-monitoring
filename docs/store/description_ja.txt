Claude.ai のサイドバーに Claude Code の使用状況をリアルタイム表示する Chrome 拡張機能です。設定パネルを開かなくても、現在のセッション残量と週間制限をひと目で確認できます。

■ 機能

・現在のセッション使用率（5時間ウィンドウ）をプログレスバーで表示
・週間制限使用率（7日間・全モデル合計）をプログレスバーで表示
・リセットまでの残り時間を自動計算（例：「4時間8分後にリセット」）
・使用率 70% 超でオレンジ警告、90% 超でレッド警告
・カードをワンクリックでミニマイズ可能
・サイドバー下部に常時表示 — チャット入力を邪魔しない

■ 動作条件

・Google Chrome（Manifest V3 対応）
・claude.ai へのログイン

■ プライバシー

外部サーバーへのデータ送信は一切行いません。すべての処理はブラウザ内で完結します。
